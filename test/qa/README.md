# QA Reports

- **DEFECT*LOG*\*.csv** – Log of defects with severity, steps, expected/actual, status.
- **TEST*SCENARIOS*\*.csv** – Test matrix (ID, scenario, type, priority, expected result, status).
- **QA*REPORT*\*.md** – Summary, acceptance coverage, defect summary, go/no-go recommendation.

Regenerate after test runs or when triaging defects.
