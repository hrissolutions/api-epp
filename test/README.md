# Test Reports

This folder holds test outputs and reports from Engineering, QA, and Review phases.

- **engineering/** – API test matrix, test defects, and execution reports
- **qa/** – Defect log, test scenarios, and QA sign-off reports
- **review/** – Code review findings and review reports

Reports are dated (e.g. `*_2026-02-17.csv`). Run `npm test` and regenerate reports as needed.
